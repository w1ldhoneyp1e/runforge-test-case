# Runforge Runs

Страница запусков AI-агентов на React, Vite и TypeScript. Данные поступают из локального асинхронного mock-сервиса; настоящий backend и запуск агентов не подключены.

## Установка и запуск

Проект проверен с Node.js 22.22.1 и Yarn 1.22.22.

```bash
yarn install --frozen-lockfile
yarn dev
```

Откройте адрес, который выведет Vite. Для просмотра production-сборки:

```bash
yarn build
yarn start
```

`yarn start` запускает `vite preview`, который раздаёт собранные файлы из `dist`.

## Проверки

```bash
yarn lint
yarn typecheck
yarn test
yarn build
```

Vitest проверяет чистые функции совместной фильтрации и поиска, а также сортировки. UI-тестов в проекте нет.

Сценарии для ручной проверки в браузере:

1. Дождаться загрузки, выбрать статус и ввести часть названия или репозитория. Убедиться, что поиск и фильтр действуют одновременно; для пустого результата нажать **Clear filters**.
2. Открыть запуск и проверить статус, детали, логи и результат; закрыть окно кнопкой, по Escape или кликом вне окна. Для длинного журнала открыть **Run full integration suite**, проверить прокрутку и копирование логов.
3. Изменить статус и проверить параметр `status` в URL, перезагрузку страницы и переходы Back/Forward. Выбрать сортировку по дате и длительности.
4. Проверить страницу на ширине от 360 px. Состояние загрузки видно благодаря задержке mock-сервиса; для проверки ошибки можно временно заставить `getRuns` отклонить Promise и затем нажать **Try again**.

Копирование в буфер обмена зависит от разрешения браузера и доступности Clipboard API (например, на `localhost` или HTTPS). Если копирование не удалось, интерфейс сообщает об ошибке.

## Структура

- `src/entities/run` — DTO, доменная модель, mapper и mock-сервис - все это, кроме мок должно бы генерироваться по схеме, но лень было добавлять.
- `src/pages/run/page.tsx` — страница и её локальный Provider.
- `src/pages/run/viewmodel` — ViewModel и чистые функции поиска, фильтрации и сортировки.
- `src/pages/run/context` — типизированный Context страницы.
- `src/pages/run/ui` и `src/pages/run/tests` — интерфейс страницы и unit-тесты.
- `src/widgets/app-sidebar` — навигационная панель приложения.
- `src/shared` — переиспользуемые UI-компоненты, иконки и форматирование.

Фильтр статуса сохраняется в URL, например `?status=failed`. Данные mock-сервиса загружаются с задержкой 650 мс, чтобы состояние загрузки было заметно.
