# AI log

При выполнении задания использовался OpenAI Codex: первоначальная реализация выполнялась моделью GPT-5.6 Terra, последующие изменения — GPT-6.1 Terra. Ассистенту были переданы PDF с функциональными требованиями, архитектурные ограничения по FSD и MVVM, скриншот демо Runforge и замечания по интерфейсу и коду.

Примеры запросов из работы:

- «Реализуй тестовое задание Runforge Junior Frontend Developer на React + Vite + TypeScript» с требованиями к модели, ViewModel, контексту и состояниям страницы.
- «Давай сделаем визуал больше похожим на это демо с сайта» с приложенным скриншотом; затем уточнялись структура страницы, sidebar и правила ESLint.
- «В правом верхнем углу логов сделаем кнопочку-иконку для копирования логов» и добавим запуск с большим журналом для проверки прокрутки.

Неудачное решение возникло при настройке зависимостей: использовались плавающие версии, и Yarn отказался устанавливать `jsdom` из-за несовместимости с Node.js 22.22.1. Ошибку обнаружили по выводу установки; версию сначала закрепили, а после решения оставить только unit-тесты чистой логики удалили UI-тесты и `jsdom`. Ещё одна проблема была замечена при просмотре интерфейса: стандартный раскрытый список выглядел как системный HTML-контрол. Его заменили стилизованным компонентом с управлением клавиатурой.

Код проверялся командами `yarn lint`, `yarn typecheck`, `yarn test` и `yarn build`. В ходе работы пользователь просматривал интерфейс и присылал замечания и скриншоты. Сценарии, которые стоит дополнительно проверить вручную перед отправкой, перечислены в README; автоматические тесты охватывают только чистую логику поиска, фильтрации и сортировки.
